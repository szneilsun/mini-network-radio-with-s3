# 网络收音机 V1.0：用户播放器与管理页面

V1.0 将中国之声和经济之声切换到央广 HTTPS 官方 HLS 地址，并在启动时自动迁移 NVS 中对应的旧地址。

V10 在 V9 的电台台标与大按钮播放器基础上，将 Web 页面分成两部分：

- `/`：普通用户播放器，适配手机与 PC，可切换电台、播放/暂停和调节音量；
- `/admin`：管理页面，保留 Wi-Fi、电台编辑、OTA、诊断、安全与恢复出厂设置；
- 普通播放器无需管理认证；管理页面及其配置接口继续使用管理员密码；
- 普通页面右上角的设置按钮可进入管理页面。

V8 在 V6 网页播放器上实现第 7、8 步：

- 路由器 Wi-Fi 掉线后每 10 秒自动重连；恢复后自动重建播放；
- HLS / AAC 播放链路长时间未恢复时采用退避重连，并从播放列表重新取最新分片；
- 播放链路重建会重设 I²S 输出；连续失败状态与原因显示在网页；
- 网页下载诊断日志；
- 网页 OTA：选择 Arduino 编译产生的 `.bin` 固件文件上传，验证成功后自动重启；
- 恢复出厂设置：清除 Wi-Fi、播放列表、音量与管理密码；
- 可设置局域网管理密码（HTTP Basic Auth，用户名 `admin`）。首次未设置密码时保持开放，设置后所有管理页面与 API 都需要登录。

配网热点仍为 `Radio-1FB8`，密码 `radio-setup`；它独立于管理密码。管理密码通过 HTTP 传输，建议只在可信局域网内设置和使用。
