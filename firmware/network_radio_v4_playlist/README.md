# 网络收音机 V4：播放列表管理

V4 基于 V3，保留首次配网、热点回退、MAX98357A 测试音和状态页，并新增可断电保存的播放列表。

- 预置凤凰音频流；
- 最多保存 16 个电台；
- 网页可新增、编辑、删除、上下排序及设置默认台；
- 频道数据保存于 NVS 的独立 `playlist` 命名空间；
- 本版仅管理列表，尚未把 HLS 流送入扬声器。测试音仍用于验证 MAX98357A。

开发阶段无论是否已配网，均保留 `Radio-1FB8` 热点（密码 `radio-setup`）；连接后访问 `http://192.168.4.1`。配网成功后也可通过设备局域网 IP 或 `http://network-radio.local` 访问。网页提供“清除 Wi-Fi 设置”。量产版应关闭此常驻热点或改为唯一密码。

MAX98357A 接线：GPIO4 → BCLK、GPIO5 → LRCLK、GPIO6 → DIN、5 V → VDD、GND 共地，扬声器只跨接 OUT+ / OUT-。`SD_MODE` 和 `GAIN` 可维持模块默认不接。
