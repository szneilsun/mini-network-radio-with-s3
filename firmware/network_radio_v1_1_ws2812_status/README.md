# ESP32-S3 网络收音机

> 2.0 系列的独立单文件工程已清理；本目录保留为历史开发目录。

历史版本：`2.0.1`

硬件：ESP32-S3 N16R8、MAX98357A、GPIO48 板载 WS2812B。配网热点为 `Radio-1FB8`，密码为 `radio-setup`。

## 构建与串口刷写

项目统一使用 16 MiB 自定义分区：OTA 元数据位于 `0x19000`，应用从 `0x20000` 开始，LittleFS 位于 `0x620000`。

请从仓库根目录使用项目构建脚本。该脚本会覆盖 Arduino-ESP32 3.3.11 中写死的旧偏移，并校验 `flash_args` 和 16 MiB 合并镜像：

```bash
./tools/build-firmware.sh
```

连接开发板后可用同一个入口编译并烧录：

```bash
./tools/build-firmware.sh --upload --port /dev/cu.usbmodemXXXX
```

不要直接使用 Arduino 的通用“上传”命令；其默认配方仍会把 OTA 数据写到 `0xE000`、把应用写到 `0x10000`，与本项目分区表不一致。

## 当前灯效

- 缓冲：红色呼吸。
- 正常播放：蓝色呼吸。
- 播放或网络错误：红色快闪。
- OTA：绿色慢闪。
- 暂停：熄灭。

管理密码使用 HTTP Basic Auth，用户名为 `admin`。建议仅在可信局域网中使用管理页面。
