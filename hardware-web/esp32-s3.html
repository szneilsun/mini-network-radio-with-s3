Pin planning

引脚规划：先避开这些占用

ESP32-S3 GPIO 矩阵很灵活，但模组存储、USB、下载与启动配置已经限定了若干脚位。

建议避开

高风险或已有板载用途

  • GPIO35–37：N16R8 的外部 Flash / OPI PSRAM 总线相关脚，即使引出也不要作为项目外设。
  • GPIO19 / 20：原生 USB D− / D+；保留 USB OTG 时不复用。
  • GPIO43 / 44：UART0 下载与日志；复用会影响 CH340C 串口。
  • GPIO0 / 3 / 45 / 46：启动配置、JTAG/输入限制等敏感用途，除非已验证启动行为，否则不作为首选。
  • GPIO48：板载 RGB LED 数据线；要使用灯效时保留。
推荐起点

本项目的低冲突分配

  • 音频 I²S：BCLK=GPIO4、LRCLK=GPIO5、DATA OUT=GPIO6、DATA IN=GPIO7。
  • microSD SPI：CS=GPIO10、MOSI=GPIO11、SCK=GPIO12、MISO=GPIO13。
  • 其余可按项目从 GPIO1/2、GPIO8–18、GPIO21 等已引出、无明显板载冲突的脚中选择。
  • 改线后必须同步修改固件的 GPIO 映射；“芯片支持”不等于“该板可随意使用”。
关于 GPIO26–34 这些脚没有出现在本板两排排针中；同时，带外部 Flash/PSRAM 的模组内部还存在存储总线占用。优先选择已引出并在上表中标注为低冲突的脚位。

Power & dimensions

供电、尺寸与安装边界

原理图可确认 5 V 到 3.3 V 的板载转换与双 USB 的二极管隔离，但稳压器的具体型号未标明。

供电

接电前先确认焊盘状态

  • USB-OTG 与 USB-ISP 的 VBUS 分别经过肖特基二极管汇入板上 5 V 网络，避免两个 USB 口直接互相回灌。
  • 板载稳压器把 5 V 转为 3.3 V；具体稳压器型号和可持续外供电流，现有图纸不能确认。
  • IN-OUT 焊盘/跳线会影响 5 V 排针的输入或输出关系。外接功放、传感器前，请先用万用表验证实际状态。
  • 大功率外设（例如 MAX98357A + 扬声器）应使用独立、足额的 5 V 电源，并与主板共地。
尺寸

安装参考

  • 主体板长约 57.15 mm，宽约 27.94 mm。
  • 天线端的最大长度标注约 63.61 mm；排针区域高度标注约 25.40 mm。
  • 天线附近请避免大面积金属、接地铜皮和高电流线束，以免削弱 Wi‑Fi / BLE 信号。

Chip capability

芯片能力与项目边界

以下来自 ESP32-S3 芯片资料，属于平台能力；并不保证全部接口均已被本开发板引出或适合同时使用。

无线

Wi‑Fi + BLE

支持 2.4 GHz 802.11 b/g/n、Bluetooth 5 LE 与 BLE Mesh；不支持 Bluetooth Classic / A2DP。

计算

双核与向量指令

双核 Xtensa LX7，最高 240 MHz；可用于 DSP、音频和轻量级边缘 AI 加速，但没有独立 NPU。

外设

I²S / SPI / USB

提供 2 路 I²S、SPI、SD/MMC、USB OTG、UART、I²C、ADC、PWM、RMT、TWAI 等能力。

安全

需由固件启用

芯片支持 Secure Boot v2 与 Flash Encryption；当前只读检测显示这两项均未启用。
