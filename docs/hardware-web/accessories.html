Power checklist

供电检查

  • 数字麦克风通常使用 3.3V，不要直接套用未知模块的 5V 接法。
  • microSD 卡核心为 3.3V 器件；裸卡座或明确标注 3.3V 的模块接 3V3，带稳压/电平转换的模块须按其丝印与原理图确认供电。
  • MAX98357A 建议使用足额 5V 供电，并与 ESP32-S3 共地；不要从板载 3V3 拉取扬声器功率。
  • 开发板排针 5V 是否可向外供电取决于 IN-OUT 焊盘/跳线状态；接入前先确认实物并测量电压。
