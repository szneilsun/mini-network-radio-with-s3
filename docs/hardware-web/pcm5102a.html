Stereo line-level DAC

GY-PCM5102：把 I2S 变成立体声线路输出

PCM5102A 是两声道音频 DAC，不是功率放大器。它适合连接有源音箱、功放或其他线路输入设备，不能直接推动无源扬声器。

2.1 Vrms 线路输出 8–384 kHz 16 / 24 / 32 bit 三线 I2S 可用

资料边界

现有资料不能证明模块级接法

“芯片能这样连接”不等于“这块 GY-PCM5102 板已经这样连接”。

已有

芯片手册

TI PCM510xA 数据手册给出了芯片性能、电源域、数字音频格式和引脚功能，可作为电气边界的依据。

缺失

模块原理图

资料中没有 GY-PCM5102 模块级原理图，无法仅凭芯片手册确认板上稳压、跳线、上拉和丝印引脚的实际连接。

上电前以实物为准 核对模块正反面丝印、卖家版本说明和万用表连通性。尤其不要把名为 VIN、VCC 或 3V3 的模块引脚直接等同于芯片的某个电源脚。
附带 btAudio 库不适用于 ESP32-S3 的蓝牙音频路径 这份旧库依赖经典蓝牙 A2DP，而 ESP32-S3 只有 Bluetooth LE，不支持经典蓝牙 A2DP。旧示例里的 GPIO25 / GPIO26 / GPIO27 接线也不是本项目的 S3 引脚方案，请勿照搬。若音源来自网络、存储或其他 BLE 应用，应另选适用于 S3 的音频数据路径和 I2S 驱动。

数字音频

I2S 三线即可工作

PCM5102A 支持标准 I2S 与左对齐格式；内部 PLL 可由位时钟恢复系统时钟，因此常规连接可以省略 MCLK。

格式

I2S / 左对齐

发送端格式必须与模块的 FMT 配置一致，否则常见现象是无声、失真或左右声道数据错位。

字长

16 / 24 / 32 bit

同时检查软件里的采样位宽、声道数和帧宽设置，不能只改一个参数。

采样率

8–384 kHz

这是芯片支持范围；最终可用组合仍取决于 S3 的 I2S 时钟配置与音源格式。

时钟

MCLK 可省略

使用内部 PLL 时，以 BCK 和 LRCK 工作，不需要额外连接 SCK/MCLK。

供电与布局

电源正确，底噪才有机会低

下列电压是 PCM5102A 芯片电源域要求；模块的外部供电入口仍需先确认板上电路。

电源域

芯片电压

  • AVDD：3.3 V 模拟电源。
  • CPVDD：3.3 V 电荷泵电源。
  • DVDD：可使用 1.8 V 或 3.3 V 数字电源。
  • 各电源脚应就近放置去耦；不要根据模块名称猜测稳压结构。
接地

减少噪声与串扰

  • S3、DAC 和后级设备必须有可靠的公共地参考。
  • 模拟输出线尽量短，远离天线、开关电源、电机和高电流扬声器回路。
  • 数字时钟线短而直接，避免与 LOUT / ROUT 长距离平行。
  • 先低音量上电；出现爆音、底噪或削波时先检查供电、地线和负载。

器件选择

PCM5102A 与 MAX98357A 不可互换

两者都接收数字音频，但模拟端的用途完全不同。

首次上电

五步排查清单

先建立最小三线链路，再逐项增加音源、后级和功能配置。

  1. 断电状态下确认模块版本、供电入口、地线和模拟输出端，不能用缺失的模块原理图作假设。
  2. 连接公共地，以及 BCK、LRCK、DIN；内部 PLL 方案不接 MCLK。
  3. 让固件的 I2S / 左对齐格式、采样率、位宽与 FMT 等硬件配置一致。
  4. 将 LOUT / ROUT 接到高阻线路输入或后级功放，并从低音量测试。
  5. 无声时依次检查静音脚、时钟、数据格式和公共地；不要改用旧 btAudio 的 A2DP 示例来验证 S3。
