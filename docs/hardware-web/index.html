 立体声 DAC

PCM5102A

高质量线路输出，适合连接有源音箱或后级功放，不能直接推喇叭。

 单声道功放

MAX98357A

I²S 数字输入、Class-D 功率输出，可直接驱动一只 4–8 Ω 扬声器。

Read first

先看这四点

GPIO35–37 不能随意使用N16R8 启用 OPI PSRAM 时会占用 GPIO26–37；虽然板上引出了 35–37，也应避开。
旧 ESP32 接线不能照抄资料中的 GPIO22/25/26/27/34 接线不适用于这块 ESP32-S3 板。
经典蓝牙代码不兼容ESP32-S3 仅支持 BLE，附带的 Bluetooth Classic A2DP 示例不能直接运行。
推荐起始 I²S 映射音频输出可先采用 BCLK=GPIO4、LRCLK=GPIO5、DATA=GPIO6，再按项目扩展。
